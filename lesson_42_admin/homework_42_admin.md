# Домашнє завдання

## Мета

Навчитися працювати з панеллю адміністратора Django, керувати користувачами, групами та дозволами доступу, а також використовувати Django Admin для керування даними навчального проєкту.

---

# Завдання 1. Налаштування Django Admin

Для моделей вашого проєкту (наприклад, **Car**, **Service**, **Customer**, **Order**, **Product**, **Category** або інших) виконайте реєстрацію в адміністративній панелі.

Для кожної моделі необхідно налаштувати:

* `list_display`
* `search_fields`
* `list_filter`
* `ordering`

### Приклад

Для моделі `Car`:

```
Відображаються:
- марка
- модель
- рік випуску
- власник
```

Також має працювати:

* пошук за маркою та моделлю;
* фільтр за роком випуску;
* сортування за роком.

---

# Завдання 2. Заповнення бази даних

Через Django Admin створіть не менше:

* 10 записів основної моделі;
* 5 записів допоміжної моделі;
* усі необхідні зв'язки між ними.

Наприклад:

* автомобілі та власники;
* товари та категорії;
* книги та автори.

---

# Завдання 3. Робота з користувачами

Створіть:

* одного суперкористувача;
* двох звичайних користувачів.

Приклад:

```
admin
manager
editor
```

---

# Завдання 4. Робота з групами

Створіть мінімум дві групи.

Наприклад:

```
Managers
Editors
```

або

```
Teachers
Students
```

---

# Завдання 5. Налаштування дозволів

Налаштуйте дозволи таким чином.

## Група Managers

Повний доступ до моделей:

* перегляд;
* створення;
* редагування;
* видалення.

---

## Група Editors

Дозволено:

* перегляд;
* створення;
* редагування.

Заборонено:

* видалення.

---

# Завдання 6. Призначення користувачів

Додайте створених користувачів до відповідних груп.

Перевірте роботу дозволів.

Наприклад:

* `manager` може виконувати всі операції;
* `editor` не може видаляти записи.

---

# Завдання 7. Налаштування адміністративної панелі

Змініть стандартні назви адміністративної панелі.

Наприклад:

```
site_header
site_title
index_title
```

Використайте власну назву вашого проєкту.

---

# Завдання 8. Додаткове (⭐)

Для однієї моделі реалізуйте щонайменше три додаткові можливості Django Admin, наприклад:

* `list_per_page`;
* `list_editable`;
* `readonly_fields`;
* `fieldsets`;
* `autocomplete_fields`;
* `date_hierarchy`;
* `prepopulated_fields`.

---
