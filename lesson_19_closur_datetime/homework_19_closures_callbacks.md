## Завдання 1. Фабрика перетворювачів напруги

На підстанції є перетворювачі, кожен із яких множить вхідну напругу на певний коефіцієнт. Замість того щоб писати окрему функцію для кожного — використай фабрику.

Напиши функцію `make_voltage_converter(factor: float)`, яка повертає функцію-перетворювач. Повернена функція приймає напругу у вольтах і повертає результат множення.

```text
Очікуваний вивід:

step_up   = make_voltage_converter(10.0)   # підвищувальний
step_down = make_voltage_converter(0.5)    # знижувальний

print(step_up(22.0))     # 220.0
print(step_down(220.0))  # 110.0
print(step_up(11.0))     # 110.0
```

## Завдання 2. Лічильник електроенергії

Кожен будинок має свій лічильник, який накопичує показники між перевірками. Усі операції лічильника мають спільний стан через замикання.

Напиши функцію `make_electricity_meter(address: str, initial_kwh: float = 0.0)`, яка повертає три функції:

- `add(kwh: float)` — додає спожиту енергію (кВт·год) і повертає поточне значення
- `reset()` — скидає показник до початкового значення і повертає його
- `report() -> str` — повертає рядок виду:  
  `"Адреса: <address> | Спожито: <kwh> кВт·год"`

```text
Очікуваний вивід:

add, reset, report = make_electricity_meter("вул. Франка, 12", 150.0)

print(add(30.5))    # 180.5
print(add(14.0))    # 194.5
print(report())     # Адреса: вул. Франка, 12 | Спожито: 194.5 кВт·год
print(reset())      # 150.0
print(report())     # Адреса: вул. Франка, 12 | Спожито: 150.0 кВт·год
```

## Завдання 3. Диспетчер аварійних подій

Диспетчерська система реєструє аварійні події на підстанціях і передає їх обробникам через callback.

Напиши функцію `make_dispatcher(station_name: str)`, яка повертає функцію `dispatch(event: str, callback)`. При виклику `dispatch` формує повідомлення виду `"[<station_name>] <event>"` і передає його в `callback`.

Реалізуй два обробники:
- `log_to_console(message: str)` — виводить повідомлення в консоль
- `log_to_file(message: str)` — дописує повідомлення у файл `dispatch_log.txt`

```text
Очікуваний вивід (консоль):

dispatch = make_dispatcher("Підстанція №7 Івано-Франківськ")

dispatch("Перевищення напруги", log_to_console)
# [Підстанція №7 Івано-Франківськ] Перевищення напруги

dispatch("Коротке замикання", log_to_console)
# [Підстанція №7 Івано-Франківськ] Коротке замикання

dispatch("Відновлення живлення", log_to_file)
# (повідомлення записується у dispatch_log.txt)
```

## Завдання 4. Сортування підстанцій

Диспетчер отримав зведену таблицю підстанцій. Потрібно вміти сортувати їх по-різному залежно від ситуації.

```python
substations = [
    {"name": "Підстанція №3", "region": "Коломия",        "load_kw": 4500},
    {"name": "Підстанція №7", "region": "Івано-Франківськ", "load_kw": 8200},
    {"name": "Підстанція №1", "region": "Калуш",           "load_kw": 3100},
    {"name": "Підстанція №9", "region": "Надвірна",        "load_kw": 6700},
]
```

Напиши функцію `make_sorter(field: str, reverse: bool = False)`, яка повертає функцію сортування. Повернена функція приймає список підстанцій і повертає відсортований список за вказаним полем.

```text
Очікуваний вивід:

sort_by_load = make_sorter("load_kw", reverse=True)
for s in sort_by_load(substations):
    print(s["name"], s["load_kw"])

# Підстанція №7  8200
# Підстанція №9  6700
# Підстанція №3  4500
# Підстанція №1  3100

sort_by_name = make_sorter("name")
for s in sort_by_name(substations):
    print(s["name"])

# Підстанція №1
# Підстанція №3
# Підстанція №7
# Підстанція №9
```

## Бонус. Захисний автомат (circuit breaker)

Справжнє «коротке замикання» в програмуванні — це **Circuit Breaker**: патерн, який зупиняє виклики після певної кількості помилок.

Напиши функцію `make_circuit_breaker(max_failures: int)`, яка повертає функцію-обгортку `protect(func)`. Функція `protect` приймає будь-яку функцію і повертає «захищену» версію: якщо при виклику виникає виняток, лічильник помилок збільшується. Коли кількість помилок досягає `max_failures` — всі наступні виклики одразу піднімають `RuntimeError("Автомат вимкнено!")` без запуску оригінальної функції.

```text
Очікуваний вивід:

breaker = make_circuit_breaker(max_failures=2)

def unstable_sensor():
    raise ConnectionError("Сенсор не відповідає")

safe_sensor = breaker(unstable_sensor)

safe_sensor()  # ConnectionError: Сенсор не відповідає  (помилка 1)
safe_sensor()  # ConnectionError: Сенсор не відповідає  (помилка 2)
safe_sensor()  # RuntimeError: Автомат вимкнено!        (автомат спрацював)
safe_sensor()  # RuntimeError: Автомат вимкнено!        (автомат спрацював)
```
