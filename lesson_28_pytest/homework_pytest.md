# Домашня робота

## Мета роботи

Навчитися створювати автоматизовані Unit-тести для Python-проєктів за допомогою бібліотеки `pytest`, використовувати фікстури та організовувати тестовий код відповідно до поширених практик розробки.

## Завдання

Для власного проєкту, який ви створювали під час курсу, необхідно реалізувати набір автоматизованих тестів.

### Обов'язково протестувати

### 1. Функції

Напишіть тести для основних функцій вашого проєкту.

Перевірте:

* коректні вхідні дані;
* некоректні вхідні дані (якщо це передбачено логікою програми);
* граничні значення;
* порожні значення (за наявності).

Приклад:

```python
add(2, 3)
add(0, 0)
add(-5, 10)
```

### 2. Класи

Якщо проєкт містить класи, необхідно протестувати:

* створення об'єктів;
* роботу методів;
* зміну стану об'єкта після виклику методів;
* правильність значень атрибутів.

### 3. Обробку помилок

Якщо у програмі використовуються винятки (`Exception`), необхідно перевірити, що вони виникають у правильних ситуаціях.

Приклад:

```python
with pytest.raises(ValueError):
    divide(10, 0)
```

### 4. Граничні значення

Перевірте ситуації, які часто викликають помилки:

* нульові значення;
* від'ємні числа;
* порожні рядки;
* порожні списки;
* мінімальні та максимальні допустимі значення.

## Використання pytest

У роботі обов'язково використати:

### assert

Для перевірки результатів:

```python
assert calculate_total([10, 20]) == 30
```

### Fixture

Створіть щонайменше одну фікстуру для підготовки тестових даних.

Наприклад:

```python
@pytest.fixture
def user():
    return User("Alex")
```

### conftest.py

Усі спільні фікстури необхідно винести до файлу:

```text
conftest.py
```

## Структура проєкту

Приклад:

```text
project/

├── app.py
├── models.py
├── conftest.py
├── test_app.py
└── test_models.py
```

## Вимоги до тестів

Кожен тест повинен:

* перевіряти одну конкретну поведінку;
* мати зрозумілу назву;
* бути незалежним від інших тестів;
* проходити успішно при запуску.

Приклади хороших назв:

```python
test_user_creation()

test_calculate_total()

test_empty_cart_returns_zero()

test_invalid_age_raises_error()
```

## Що необхідно здати

Створіть Pull Request, який містить:

### 1. Код тестів

Файли з тестами:

```text
test_*.py
```

а також файл:

```text
conftest.py
```

### 2. Логи успішного запуску тестів

Додайте до Pull Request скріншот або текстовий лог виконання команди:

```bash
pytest -v
```

Приклад:

```text
======================== test session starts ========================

test_app.py::test_add PASSED
test_app.py::test_subtract PASSED
test_app.py::test_divide PASSED
test_models.py::test_user_creation PASSED

======================== 4 passed ========================
```

## Мінімальні вимоги

Робота повинна містити:

* не менше 10 тестів;
* хоча б 1 fixture;
* файл conftest.py;
* лог успішного запуску тестів.

Опційно:
* перевірка виклику винятку через pytest.raises();

## Критерії оцінювання

### 100 балів

* протестовані всі ключові частини проєкту;
* є перевірка помилок;
* використані fixtures;
* використаний conftest.py;
* усі тести проходять успішно;
* код тестів читабельний та акуратний.

### 75 балів

* більшість функцій протестовано;
* використано pytest;
* усі тести проходять.

### 50 балів

* присутні лише базові перевірки;
* відсутні fixtures або conftest.py;
* протестовано лише частину функціоналу.

### 0 балів

* тести не запускаються;
* тести падають;
* відсутні логи запуску;
* відсутній код тестів.

## Важливо

✅ Усі тести повинні завершуватися успішно.

Перед створенням Pull Request обов'язково виконайте:

```bash
pytest -v
```

та переконайтеся, що немає статусів:

```text
FAILED
ERROR
```

У фінальному результаті повинні бути лише:

```text
PASSED
```
