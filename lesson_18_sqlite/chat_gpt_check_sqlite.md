## Що я б додав обов'язково

### 1. Вимога використовувати контекстний менеджер

Багато студентів забудуть закривати з'єднання.

Додати в загальні вимоги:

```markdown
- Після завершення роботи із базою даних з'єднання повинно бути закрите.
- Рекомендується використовувати конструкцію:

with get_connection() as conn:
    ...
```

### 2. Явно вказати AUTOINCREMENT

Зараз таблиці описані абстрактно.

Початківці можуть зробити:

```sql
id INTEGER
```

замість

```sql
id INTEGER PRIMARY KEY AUTOINCREMENT
```

Я б додав:

```markdown
Для всіх таблиць поле id повинно створюватися як:

id INTEGER PRIMARY KEY AUTOINCREMENT
```

### 3. Перевірка результату UPDATE та DELETE

Зараз є функції:

```python
update_issue_status(...) -> bool
delete_issue(...) -> bool
```

але не пояснено як визначати True/False.

Я б додав:

```markdown
Функція повинна повертати True, якщо було змінено хоча б один запис,
та False, якщо запис із таким id не знайдено.
```

Це навчить використовувати:

```python
cursor.rowcount
```

## Що бажано додати

### 4. ORDER BY

У програмі курсу далі буде багато SQL.

Зараз студенти можуть отримувати записи в довільному порядку.

Я б додав вимогу:

```markdown
У функціях отримання списків дані повинні бути відсортовані за id.
```

Наприклад:

```sql
SELECT *
FROM issues
ORDER BY id;
```

### 5. Перевірка роботи Foreign Key

Зараз FK створюються, але не перевіряються.

Додати бонус або перевірку:

```markdown
Спробуйте додати коментар до неіснуючої задачі.
Переконайтесь, що SQLite не дозволяє порушити зовнішній ключ.
```

Це добре закріплює тему.
