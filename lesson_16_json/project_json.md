
# ПРАКТИКА

На практиці кожен студент відкриває свій навчальний проєкт і додає до нього JSON-збереження. Нижче — конкретні завдання для кожного проєкту.

## Проєкт 1: Task & Bug Manager

**Завдання:**

1. Додати до класу `Issue` методи `to_dict()` та `from_dict()`
2. У пакеті створити модуль `storage.py` з двома функціями: `load_issues(filepath)` та `save_issues(filepath, issues)`
3. Підключити збереження у `TaskManager`: при старті — завантажувати з файлу, при кожній зміні — зберігати
4. Перевірити: закрити програму, запустити знову — задачі на місці

## Проєкт 2: Expense & Budget Tracker

**Завдання:**

1. Додати `to_dict()` та `from_dict()` до класів `Income`, `Expense` та `Budget`
2. Створити модуль `storage.py` з функціями `load_transactions()`, `save_transactions()`, `load_budgets()`, `save_budgets()`
3. Підключити у `ExpenseTracker`
4. Перевірити повний цикл: додати транзакцію, закрити, запустити, побачити транзакцію

## Проєкт 3: Service Management System

**Завдання:**

1. Додати `to_dict()` та `from_dict()` до класів `Client`, `Order` (та підкласів), `Service`
2. Створити `storage.py` з функціями збереження і завантаження для кожного типу сутностей
3. Підключити у `ServiceManager`
4. Перевірити: зареєструвати клієнта і замовлення, перезапустити — дані збережено
