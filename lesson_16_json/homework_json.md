# Домашнє завдання: Робота з JSON

## Контекст

Уяви, що ти розробляєш цифровий архів для збирачів українського фольклору. Експедиції виїжджають у села, записують пісні, казки, прислів'я та легенди від місцевих оповідачів — і все це потрібно зберігати, оновлювати та передавати між дослідниками у форматі JSON.

## Завдання 1: Перші кроки — серіалізація вручну

Створи словник, який описує одну фольклорну одиницю — запис із польової експедиції.

Словник має містити:
- назву твору (`title`)
- жанр (`genre`) — наприклад: `"пісня"`, `"казка"`, `"легенда"`, `"прислів'я"`
- регіон запису (`region`)
- ім'я оповідача (`narrator`)
- рік запису (`year`)
- текст або короткий зміст (`content`)
- теги (`tags`) — список рядків
- чи перевірено автентичність (`verified`) — булеве значення

**Виконай:**

1. Перетвори словник на JSON-рядок за допомогою `json.dumps()`. Виведи рядок і його тип.
2. Виведи той самий рядок із `indent=4` та `ensure_ascii=False`. Порівняй результати.
3. Відновити об'єкт із рядка через `json.loads()`. Переконайся, що тип — `dict`, і виведи кілька полів.

## Завдання 3: Клас `FolkloreRecord`

Створи клас **`FolkloreRecord`**, який представляє один запис з архіву.

**Атрибути конструктора:**
- `title`, `genre`, `region`, `narrator`, `year`, `content`, `tags`, `verified`

**Методи:**

1. `to_dict()` — повертає словник із усіма атрибутами
2. `from_dict(data)` — класовий метод, що створює об'єкт зі словника
3. `__str__()` — повертає:
```
[пісня] "Ой у лузі червона калина" — Полтавщина, 1932 (оповідач: Ганна Остапенко)
```

**Перевір повний цикл:**
- Створи 3 об'єкти `FolkloreRecord`
- Збережи їх у файл `records.json` через `to_dict()`
- Завантаж із файлу і відтвори об'єкти через `from_dict()`
- Виведи кожен через `__str__()`

## Завдання 4: Клас `FieldExpedition`

Створи клас **`FieldExpedition`** — польова експедиція збирача фольклору.

**Атрибути:**
- `expedition_id` — унікальний номер
- `researcher` — ім'я дослідника
- `location` — село або місто
- `date` — дата у форматі рядка `"РРРР-ММ-ДД"`
- `records` — список об'єктів `FolkloreRecord`, початково порожній

**Методи:**

1. `add_record(record)` — додає об'єкт `FolkloreRecord` до списку. Якщо запис із таким `title` вже є — повертає `"Запис '<title>' вже є в експедиції"`

2. `remove_record(title)` — видаляє запис за назвою. Якщо не знайдено — повертає `"Запис '<title>' не знайдено"`

3. `find_by_genre(genre)` — повертає список усіх записів заданого жанру. Якщо нічого немає — порожній список

4. `to_dict()` — повертає словник, де `records` — це список словників через `to_dict()` кожного запису

5. `from_dict(data)` — класовий метод, що відновлює об'єкт разом із усіма вкладеними `FolkloreRecord`

6. `save(filepath)` — зберігає експедицію у JSON-файл

7. `load(filepath)` — класовий метод, що завантажує експедицію з файлу. Обробляє `FileNotFoundError` та `json.JSONDecodeError`

**Перевір:**
- Створи експедицію, додай 4 записи різних жанрів
- Збережи у файл
- Завантаж з файлу в новий об'єкт
- Знайди всі пісні через `find_by_genre()`
- Видали один запис і збережи знову

## Завдання 5: Центральний архів — робота з колекцією файлів

Є папка з кількома JSON-файлами експедицій. Напиши **три окремі функції** для роботи з архівом.

**Функція `merge_archives(filepaths)`:**
- Приймає список шляхів до JSON-файлів експедицій
- Завантажує всі записи з усіх файлів
- Повертає єдиний список усіх `FolkloreRecord` з усіх експедицій
- Якщо якийсь файл не існує або пошкоджений — пропускає його і виводить попередження

**Функція `filter_records(records, genre=None, region=None, verified=None)`:**
- Приймає список `FolkloreRecord` і необов'язкові фільтри
- Повертає лише ті записи, що відповідають усім переданим фільтрам
- Якщо жоден фільтр не передано — повертає всі записи

**Функція `export_summary(records, filepath)`:**
- Приймає список `FolkloreRecord`
- Зберігає у JSON-файл не повні записи, а лише зведення:
```json
[
    {
        "title": "Ой у лузі червона калина",
        "genre": "пісня",
        "region": "Полтавщина",
        "verified": true
    }
]
```

**Перевір:**
- Створи 2–3 файли експедицій
- Об'єднай їх через `merge_archives()`
- Відфільтруй перевірені записи з певного регіону
- Збережи зведення через `export_summary()`
