# Домашнє завдання до проєктів

## Мета

Підвищити рівень безпеки навчального Django-проєкту, використовуючи вбудовані механізми захисту Django та рекомендації для Production-середовища.

---

## Завдання 1. Захист HTML-форм від CSRF

Перевірте всі HTML-форми у своєму проєкті.

Необхідно:

* додати `{% csrf_token %}` до кожної форми, що використовує метод `POST`;
* перевірити, що без CSRF-токена сервер повертає помилку **403 Forbidden**;
* зробити короткий опис принципу роботи CSRF-захисту.

---

## Завдання 2. Перенесення секретів у змінні середовища

Створіть файл `.env` та перенесіть до нього:

* `SECRET_KEY`;
* `DEBUG`;
* параметри підключення до бази даних (за потреби).

У файлі `settings.py` реалізуйте завантаження цих значень за допомогою `python-dotenv`.

> **Важливо:** файл `.env` повинен бути доданий до `.gitignore`.

---

## Завдання 3. Налаштування Production-параметрів

Виконайте базові налаштування безпеки:

* встановіть `DEBUG = False`;
* заповніть `ALLOWED_HOSTS`;
* увімкніть:

```python
SESSION_COOKIE_SECURE = True
SESSION_COOKIE_HTTPONLY = True
CSRF_COOKIE_SECURE = True
```

Поясніть призначення кожного параметра.

---

## Завдання 4. Перевірка middleware

Переконайтеся, що у проєкті використовуються:

* `SecurityMiddleware`;
* `CsrfViewMiddleware`;
* `XFrameOptionsMiddleware`.

Опишіть, від яких атак захищає кожен із них.

---

## Завдання 5. Захист від SQL Injection

Перегляньте свій код.

Переконайтеся, що:

* усі запити до бази виконуються через Django ORM або параметризовані SQL-запити;
* відсутня конкатенація SQL-рядків із введеними користувачем даними.

За потреби виправте небезпечні місця.

---

## Завдання 6. Перевірка готовності до Production

Запустіть команду:

```bash
python manage.py check --deploy
```

Проаналізуйте всі попередження.

За можливості усуньте їх та зробіть короткий звіт:

* які рекомендації були отримані;
* які зміни ви внесли;
* які попередження залишилися та чому.

---

# Додаткове завдання ⭐

Дослідіть механізм **Content Security Policy (CSP)**.

1. Встановіть пакет `django-csp`.
2. Налаштуйте базову політику безпеки.
3. Перевірте, що застосунок працює коректно після її увімкнення.
4. Поясніть, які типи атак допомагає запобігти CSP.

---

# Що необхідно здати

* Посилання на Pull Request або GitHub-репозиторій.
* Оновлений код проєкту.
* Файл `.env.example` (без секретних значень).
* Короткий звіт (1–2 сторінки) із описом виконаних налаштувань та результатів команди `python manage.py check --deploy`.
* Скріншоти або журнал виконання перевірок (за бажанням).
