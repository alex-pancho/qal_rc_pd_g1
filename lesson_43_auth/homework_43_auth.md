# Домашнє завдання №43

## Автентифікація та авторизація користувачів у Django

> **Мета:** навчитися реалізовувати систему реєстрації, входу та виходу користувачів, захищати сторінки та керувати доступом до функціональності.

---

# Завдання 1. Реєстрація користувачів ⭐

Додайте до свого проєкту сторінку реєстрації.

Користувач повинен мати можливість:

* створити новий обліковий запис;
* ввести логін;
* пароль;
* підтвердження пароля.

Після успішної реєстрації користувача необхідно перенаправити на сторінку входу.

---

# Завдання 2. Вхід та вихід із системи ⭐

Реалізуйте систему входу та виходу.

Необхідно:

* створити сторінку Login;
* використати `LoginView`;
* створити кнопку **Увійти**;
* створити кнопку **Вийти**;
* використати `LogoutView`.

Після виходу користувач повинен бути перенаправлений на головну сторінку.

---

# Завдання 3. Меню навігації ⭐

Залежно від стану користувача меню повинно змінюватися.

### Якщо користувач не увійшов

Відображати:

* Головна
* Реєстрація
* Увійти

### Якщо користувач авторизований

Відображати:

* Головна
* Профіль
* Вийти

---

# Завдання 4. Захист сторінок ⭐⭐

Створіть сторінку

```
/profile/
```

На ній необхідно показати:

* логін користувача;
* email;
* дату реєстрації.

Сторінка повинна відкриватися лише після входу.

Для цього використайте

```python
@login_required
```

---

# Завдання 5. Привітання користувача ⭐⭐

Після входу у верхній частині сайту необхідно показувати повідомлення

```
Вітаємо, Oleksandr!
```

або

```
Hello, Ivan!
```

Якщо користувач не авторизований — повідомлення не показується.

---

# Завдання 6. Захист створення даних ⭐⭐

Обмежте можливість створення нових записів у вашому проєкті.

Наприклад:

* ToDo — створювати задачі може лише авторизований користувач.
* Blog — створювати статті може лише авторизований користувач.
* Car Service — додавати автомобілі може лише авторизований користувач.

Для цього використайте

```python
@login_required
```

---

# Завдання 7. Власник запису ⭐⭐⭐

Під час створення нового об'єкта автоматично зберігайте користувача, який його створив.

Наприклад

```python
author = request.user
```

або

```python
owner = request.user
```

Після цього виведіть власника на сторінці детального перегляду.

---

# Завдання 8. Редагування тільки своїх записів ⭐⭐⭐

Користувач повинен мати можливість редагувати **лише власні** записи.

Якщо він відкриє запис іншого користувача — необхідно показати повідомлення:

```
Доступ заборонено.
```

або повернути помилку **403 Forbidden**.

---

# Завдання 9. Адміністратор ⭐⭐⭐

Створіть суперкористувача.

Через Django Admin:

* створіть ще двох звичайних користувачів;
* перевірте можливість входу кожним із них;
* переконайтеся, що вони не мають доступу до адміністративної панелі.

---

# Завдання 10. Додаткове (за бажанням) ⭐⭐⭐⭐

Реалізуйте сторінку **"Мої записи"**.

Вона повинна показувати лише об'єкти поточного користувача.

Наприклад:

```
Мої задачі

✓ Купити молоко
✓ Написати домашнє завдання
✓ Закінчити проєкт
```

або

```
Мої статті
```

або

```
Мої автомобілі
```

залежно від вашого навчального проєкту.
