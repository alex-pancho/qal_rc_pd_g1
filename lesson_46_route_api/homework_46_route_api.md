# Домашнє завдання №46

## CRUD API та маршрутизація в Django REST Framework

### Мета

Розширити REST API курсового проєкту, реалізувавши повний набір CRUD-операцій за допомогою **ModelViewSet** та **DefaultRouter**.

---

# Завдання

### 1. Створіть ViewSet для всіх основних моделей

Для кожної моделі вашого проєкту (наприклад: `Car`, `Client`, `Order`, `Service`, `Book`, `Product` тощо) створіть окремий `ModelViewSet`.

Кожен ViewSet повинен містити:

* `queryset`
* `serializer_class`

---

### 2. Налаштуйте маршрутизацію

Створіть файл `api/urls.py`.

Використайте `DefaultRouter`.

Зареєструйте всі ViewSet.

Підключіть маршрути до головного `urls.py`.

---

### 3. Реалізуйте повний CRUD

Для кожної моделі повинні працювати:

* отримання списку;
* отримання одного запису;
* створення;
* повне оновлення (`PUT`);
* часткове оновлення (`PATCH`);
* видалення (`DELETE`).

Перевірте роботу через **Browsable API**, **Postman** або **Insomnia**.

---

### 4. Реалізуйте власний endpoint

Для однієї моделі створіть власну дію за допомогою декоратора `@action`.

Приклади:

* активація користувача;
* архівація запису;
* зміна статусу замовлення;
* позначення автомобіля як доступного;
* завершення заявки.

Власний endpoint повинен використовувати відповідний HTTP-метод (`POST` або `GET`) та повертати JSON-відповідь.

---

### 5. Додайте фільтрацію

Перевизначте метод `get_queryset()` хоча б в одному ViewSet.

Реалізуйте фільтрацію за параметром URL.

Наприклад:

```text
GET /api/cars/?brand=Toyota

GET /api/orders/?status=completed

GET /api/books/?author=King
```

---

### 6. Автоматичне заповнення полів

Для одного ViewSet реалізуйте метод `perform_create()`.

Наприклад:

* автоматично встановлюйте автора запису;
* дату створення;
* поточного користувача;
* початковий статус.

---

## Для курсового проєкту

Ваш REST API повинен містити:

* не менше **трьох моделей**;
* окремий **Serializer** для кожної моделі;
* окремий **ModelViewSet** для кожної моделі;
* маршрутизацію через `DefaultRouter`;
* повний набір CRUD-операцій;
* хоча б **один власний endpoint** (`@action`);
* хоча б **один приклад фільтрації** через параметри запиту.

---

# Що необхідно здати

Посилання на GitHub-репозиторій із проєктом.

У файлі **README.md** додайте:

1. короткий опис проєкту;
2. список реалізованих моделей;
3. перелік доступних API-маршрутів;
4. приклади HTTP-запитів (GET, POST, PATCH, DELETE);
5. приклад використання власного endpoint (`@action`);
6. приклад фільтрації через query parameters.

Реалізуйте **вкладений API** для пов'язаних моделей.

Наприклад:

* `/api/orders/5/items/`
* `/api/books/3/reviews/`
* `/api/clients/2/orders/`

Або додайте:

* пагінацію результатів;
* сортування (`ordering`);
* пошук (`search`) за допомогою можливостей Django REST Framework.

Ці можливості підготують ваш проєкт до наступного заняття, присвяченого автентифікації, дозволам доступу та тестуванню REST API.
