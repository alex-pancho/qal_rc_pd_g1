# Домашнє завдання: Ітератори та Генератори

## Контекст

«Ти малий скажи малому, хай малий малому скаже, хай малий теля прив'яже» — це ланцюжок: один передає іншому, той — наступному, і так до кінця. Саме так працюють ітератори і генератори: елемент за елементом, крок за кроком, не завантажуючи все одразу.

## Завдання 1: Ітератор «Ланцюжок доручень»

Створи клас-ітератор **ChainOfOrders**, який моделює передачу доручення по ланцюжку людей.

**Конструктор** приймає список імен — учасників ланцюжка.

**Поведінка:**
* При кожному виклику `next()` повертає рядок у форматі:
  * для першого: `"Старший каже Михайлику: передай далі!"`
  * для проміжних: `"Михайлик каже Василькові: передай далі!"`
  * для останнього: `"Василько каже: теля прив'язав!"`
* Коли ланцюжок вичерпано — викидає `StopIteration`

### 🔧 Вимоги:

* Реалізувати методи `__iter__()` та `__next__()`
* Клас має працювати у циклі `for`
* Якщо список порожній — одразу `StopIteration`
* Якщо один елемент — `"<ім'я> каже: теля прив'язав!"`

### 📝 Приклад очікуваної роботи:

```python
chain = ChainOfOrders(["Дід", "Батько", "Михайлик", "Василько"])

for message in chain:
    print(message)
```

Очікуваний вивід:
```
Дід каже Батькові: передай далі!
Батько каже Михайлику: передай далі!
Михайлик каже Василькові: передай далі!
Василько каже: теля прив'язав!
```

## Завдання 2: Генератор «Чутка по селу»

Напиши **генераторну функцію** `village_rumor(start_message, people)`, яка моделює, як чутка передається по селу і змінюється з кожним переказом.

**Параметри:**
* `start_message` — початкове повідомлення
* `people` — список імен

**Поведінка:**
* Перша ітерація: повертає оригінальне повідомлення від першої людини
* Кожна наступна: людина «переказує по-своєму» — додає в кінець повідомлення `"(переказав <ім'я>)"`
* Остання людина додає `"(і всі дізналися!)"` замість звичайного переказу

### 📝 Приклад очікуваної роботи:

```python
for version in village_rumor("Теля втекло!", ["Горпина", "Параска", "Явдоха", "Оксана"]):
    print(version)
```

Очікуваний вивід:
```
Горпина каже: "Теля втекло!"
Параска переказує: "Теля втекло! (переказала Горпина)"
Явдоха переказує: "Теля втекло! (переказала Горпина) (переказала Параска)"
Оксана переказує: "Теля втекло! (переказала Горпина) (переказала Параска) (переказала Явдоха) (і всі дізналися!)"
```

## Завдання 4: Нескінченний генератор «Черга на толоці»

Напиши **нескінченний генератор** `toloka_queue(workers)`, який нескінченно по колу повертає імена робітників — як чергування на толоці (колективна робота по колу).

**Поведінка:**
* Отримує список імен
* Нескінченно їх циклить: після останнього — знову перший
* Кожен раз повертає рядок `"Черга: <ім'я>"`

**Використай** `itertools.islice()` або власний лічильник, щоб зупинити нескінченний генератор після потрібної кількості ітерацій.

### 📝 Приклад очікуваної роботи:

```python
queue = toloka_queue(["Іван", "Марія", "Степан"])

# Взяти перші 7 чергувань
for turn in itertools.islice(queue, 7):
    print(turn)
```

Очікуваний вивід:
```
Черга: Іван
Черга: Марія
Черга: Степан
Черга: Іван
Черга: Марія
Черга: Степан
Черга: Іван
```

## Завдання 5: «Де загубилось теля?» — ліниве читання

Є великий «журнал подій» — список із тисяч рядків (уяви, що це файл). Потрібно знайти **перший** рядок, де теля нарешті прив'язали, не завантажуючи весь журнал у пам'ять одразу.

Напиши **генераторну функцію** `find_calf(log)`, яка:
* приймає будь-який ітерований об'єкт `log` (список рядків або файл)
* по одному переглядає рядки
* як тільки знаходить рядок, що містить слово `"прив'язав"` або `"прив'язала"` — повертає його через `yield` і зупиняється

Потім використай `next()` щоб отримати лише перший результат.

### 📝 Приклад:

```python
journal = [
    "Михайлик отримав доручення",
    "Михайлик передав Василькові",
    "Василько загрався",
    "Василько передав Оленці",
    "Оленка прив'язала теля біля хліва",
    "Оленка пішла додому",
    "Дід заспокоївся",
]

result = next(find_calf(journal))
print(result)
# Оленка прив'язала теля біля хліва
```
