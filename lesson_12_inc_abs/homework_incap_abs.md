# Домашнє завдання: Інкапсуляція та Абстракція

## Завдання 1: Клас `MagicCreature`

Створи **абстрактний** клас **MagicCreature**, який представляє казкову істоту зі східнослов'янської міфології.

Кожна істота має:

* **ім'я** (`name`)
* **рівень магії** (`_magic_level`) — від 1 до 10, **захищений** атрибут
* **здоров'я** (`__health`) — від 0 до 100, **приватний** атрибут
* **чи жива істота** (`__alive`)

### 🔧 Вимоги до класу:

1. **Конструктор** приймає ім'я, рівень магії та здоров'я. При створенні перевіряє значення через приватні методи валідації:
   * рівень магії — лише від 1 до 10, інакше → `ValueError: "Рівень магії має бути від 1 до 10!"`
   * здоров'я — лише від 0 до 100, інакше → `ValueError: "Здоров'я має бути від 0 до 100!"`

2. **Property `health`**
   * геттер повертає поточне здоров'я
   * сеттер перевіряє діапазон; якщо здоров'я стає 0 або менше — встановлює 0 і позначає істоту як мертву (`__alive = False`)

3. **Property `magic_level`**
   * геттер повертає рівень магії
   * сеттер перевіряє діапазон

4. **Property `is_alive`**
   * тільки геттер — повертає `True` або `False`

5. **Абстрактний метод `use_ability()`**
   * кожна підістота **зобов'язана** реалізувати цей метод

6. **Абстрактний метод `describe()`**
   * повертає опис істоти у довільному форматі — кожен підклас описує себе по-своєму

7. **Метод `take_damage(amount)`**
   * зменшує здоров'я на `amount`
   * якщо істота вже мертва — повертає `"<ім'я> вже переміг смерть... або ні."`

8. **Метод `__str__()`**:
   ```
   <ім'я> | Магія: <рівень> | HP: <здоров'я> | Живий: <True/False>
   ```

## Завдання 2: Підкласи казкових істот

Створи **три підкласи** на основі `MagicCreature`.

### 🧙 Клас `Molfar` (Мольфар)

Мольфар — карпатський чаклун, який керує силами природи.

**Додаткові атрибути:**
* **стихія** (`element`) — наприклад, `"вогонь"`, `"вода"`, `"вітер"`, `"земля"`
* **запас заклинань** (`__spells`) — ціле число, початкове значення задається при створенні

**Реалізувати:**

* `use_ability()` — якщо заклинань більше 0, зменшує запас на 1 і повертає `"Мольфар <ім'я> закликає <стихія>! Залишилось заклинань: <кількість>"`. Якщо заклинань немає — `"Мольфар <ім'я> виснажений — сила стихій покинула його!"`

* `describe()` — повертає:
   ```
   Мольфар <ім'я>, повелитель стихії <element>. Рівень магії: <magic_level>
   ```

* **Property `spells`** із геттером та сеттером (лише невід'ємні значення)

### 🌊 Клас `Rusalka` (Русалка)

Русалка — небезпечна водяна істота, що принаджує мандрівників.

**Додаткові атрибути:**
* **річка** (`river`) — де мешкає
* **__charm_power** — сила чар від 1 до 5, **приватний** атрибут

**Реалізувати:**

* `use_ability()` — повертає `"Русалка <ім'я> з річки <river> зачаровує мандрівника! Сила чар: <charm_power>"`. Якщо `charm_power` дорівнює 5 — додає `" Ніхто не встоїть!"`

* `describe()` — повертає:
   ```
   Русалка <ім'я>, мешканка річки <river>. Сила чар: <charm_power>/5
   ```

* **Property `charm_power`** із геттером та сеттером (діапазон 1–5, інакше `ValueError`)

### 🐺 Клас `Perelesnyk` (Перелесник)

Перелесник — вогняний дух, що літає між світами.

**Додаткові атрибути:**
* **швидкість польоту** (`__speed`) — від 1 до 100, **приватний** атрибут
* **форма** (`form`) — `"вогняна куля"` або `"людська"`, змінюється методом

**Реалізувати:**

* `use_ability()` — повертає `"Перелесник <ім'я> мчить крізь ніч зі швидкістю <speed>! Форма: <form>"`. Якщо форма `"людська"` — додає `" Ніхто не здогадається..."`

* `describe()` — повертає:
   ```
   Перелесник <ім'я>. Швидкість: <speed>. Зараз у формі: <form>
   ```

* **Метод `change_form()`** — перемикає між `"вогняна куля"` та `"людська"` і повертає `"Перелесник перетворився на <нова форма>!"`

* **Property `speed`** із геттером та сеттером (діапазон 1–100)

## Завдання 3: Клас `EnchantedForest`

Створи клас **EnchantedForest** — зачарований ліс, де мешкають усі казкові істоти.

**Атрибути:**
* **назва лісу** (`name`)
* **список істот** (`__creatures`) — **приватний**
* **максимальна кількість мешканців** (`capacity`)

### ➕ Методи:

1. **`add_creature(creature)`**
   * приймає об'єкт підкласу `MagicCreature`
   * якщо місць немає — `"Зачарований ліс <name> переповнений!"`
   * якщо істота мертва — `"Мертві істоти не можуть оселитись у лісі!"`
   * якщо вже є — `"<ім'я> вже мешкає у цьому лісі!"`

2. **`remove_creature(name)`**
   * видаляє за ім'ям
   * якщо не знайдено — `"Істоту <name> не знайдено у лісі!"`

3. **`most_powerful()`**
   * повертає істоту з найвищим `magic_level`
   * якщо ліс порожній — `"Ліс порожній — нема кому чаклувати!"`

4. **`attack_intruder(intruder_name)`**
   * кожна жива істота у лісі викликає свій `use_ability()`
   * результат — список рядків від кожної істоти
   * якщо нікого немає — `"Ліс беззахисний перед <intruder_name>!"`

5. **`census()`**
   * повертає список рядків через `describe()` кожної істоти
   * якщо порожній — `"Ліс порожній"`

6. **Property `creatures_count`**
   * тільки геттер — кількість живих істот у лісі

## 📝 Приклад очікуваної роботи:

```python
forest = EnchantedForest("Чорний Ліс", capacity=5)

molfar = Molfar("Юрій", magic_level=8, health=90, element="вогонь", spells=3)
rusalka = Rusalka("Калина", magic_level=6, health=100, river="Дніпро", charm_power=5)
perelesnyk = Perelesnyk("Іскра", magic_level=7, health=85, speed=95, form="вогняна куля")

forest.add_creature(molfar)
forest.add_creature(rusalka)
forest.add_creature(perelesnyk)

print(forest.most_powerful())
print(forest.attack_intruder("мисливець"))

molfar.take_damage(90)
print(molfar.is_alive)

print(forest.census())
```

## Бонус 🏆

Якщо хочеш ускладнити:

* Додай до `EnchantedForest` метод `heal_all(amount)`, який відновлює здоров'я всіх **живих** істот на `amount` одиниць (але не більше 100).
* Додай до `MagicCreature` абстрактний метод `weakness()` — кожна істота має свою слабкість. Наприклад, Мольфар — `"протилежна стихія"`, Русалка — `"сонячне світло"`, Перелесник — `"священна вода"`. Використай цей метод у `attack_intruder()`, щоб виводити слабкість кожної істоти разом із її здібністю.
