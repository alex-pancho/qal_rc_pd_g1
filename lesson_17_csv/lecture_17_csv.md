# Заняття 17. Робота з CSV-файлами

## Що таке CSV і навіщо він потрібен

CSV (Comma-Separated Values) — це текстовий формат зберігання табличних даних, де кожен рядок відповідає одному запису, а значення всередині рядка розділені комами (або іншим роздільником). Попри свою простоту, CSV залишається одним із найпоширеніших форматів обміну даними: його підтримують Excel, Google Sheets, більшість баз даних та практично кожна аналітична система.

Типовий CSV-файл виглядає так:

```
name,age,city
Олена,25,Київ
Максим,30,Харків
Дарина,22,Львів
```

Перший рядок зазвичай містить заголовки стовпців — це не обов'язкова вимога формату, але стандартна практика.

## Модуль `csv`

Python має вбудований модуль `csv`, який бере на себе всі складнощі роботи з цим форматом: правильне екранування значень із комами, обробку лапок, підтримку різних роздільників. Намагатися розбирати CSV вручну через `split(",")` — погана ідея: варто лише зіткнутися з полем, що містить кому всередині лапок, і такий підхід зламається.

## Читання файлів: `reader`

Базовий спосіб читати CSV — це `csv.reader`. Він повертає ітератор, де кожен елемент — це список рядкових значень одного рядка.

```python
import csv

with open("students.csv", encoding="utf-8") as file:
    reader = csv.reader(file)
    for row in reader:
        print(row)
```

Якщо файл має заголовки і вони не потрібні в обробці, перший рядок пропускають через `next(reader)`:

```python
with open("students.csv", encoding="utf-8") as file:
    reader = csv.reader(file)
    next(reader)  # пропускаємо заголовок
    for row in reader:
        print(row)
```

## Запис у файли: `writer`

`csv.writer` дозволяє записувати дані рядок за рядком. Метод `writerow` приймає список значень і перетворює його на правильно відформатований CSV-рядок.

```python
import csv

data = [
    ["name", "age", "city"],
    ["Олена", 25, "Київ"],
    ["Максим", 30, "Харків"],
]

with open("output.csv", "w", newline="", encoding="utf-8") as file:
    writer = csv.writer(file)
    writer.writerows(data)
```

Зверніть увагу на параметр `newline=""` при відкритті файлу для запису — він необхідний на Windows, щоб уникнути подвоєних переносів рядків.

Якщо потрібно записати кілька рядків одразу, зручніше використовувати `writerows` замість циклу з `writerow`.

## `DictReader`: читання у словники

`csv.DictReader` — зручніша альтернатива `reader` для файлів із заголовками. Він автоматично читає перший рядок як ключі і повертає кожен наступний рядок у вигляді словника.

```python
import csv

with open("students.csv", encoding="utf-8") as file:
    reader = csv.DictReader(file)
    for row in reader:
        print(row["name"], row["age"])
```

Замість `row[0]` і `row[1]` можна звертатися до полів за назвою — код стає зрозумілішим і стійкішим до змін у порядку стовпців.

## `DictWriter`: запис зі словників

`csv.DictWriter` — парний інструмент для запису: він приймає словники і записує значення в правильному порядку відповідно до заданих заголовків.

```python
import csv

fieldnames = ["name", "age", "city"]
rows = [
    {"name": "Олена", "age": 25, "city": "Київ"},
    {"name": "Максим", "age": 30, "city": "Харків"},
]

with open("output.csv", "w", newline="", encoding="utf-8") as file:
    writer = csv.DictWriter(file, fieldnames=fieldnames)
    writer.writeheader()
    writer.writerows(rows)
```

`writeheader()` записує перший рядок із назвами стовпців. Якщо словник містить ключ, якого немає в `fieldnames`, `DictWriter` за замовчуванням викине `ValueError` — це захищає від випадкових помилок у структурі даних.

## Діалекти CSV

Не всі CSV-файли використовують кому як роздільник. У деяких регіонах стандартом є крапка з комою (особливо в локалізованих версіях Excel), у деяких форматах — табуляція. Для таких випадків `csv.reader` та `csv.writer` приймають параметр `delimiter`:

```python
reader = csv.reader(file, delimiter=";")
writer = csv.writer(file, delimiter="\t")
```

Якщо певний набір параметрів використовується постійно, його можна зафіксувати як _діалект_ — іменований набір налаштувань:

```python
import csv

csv.register_dialect(
    "semicolon",
    delimiter=";",
    quotechar='"',
    quoting=csv.QUOTE_MINIMAL,
)

with open("data.csv", encoding="utf-8") as file:
    reader = csv.reader(file, dialect="semicolon")
    for row in reader:
        print(row)
```

Модуль має кілька вбудованих діалектів: `excel` (роздільник — кома, як у Microsoft Excel), `excel-tab` (роздільник — табуляція) та `unix`. Переглянути список доступних діалектів можна через `csv.list_dialects()`.

## Читання великих файлів

`csv.reader` є ітератором — він читає файл рядок за рядком, не завантажуючи весь вміст у пам'ять одночасно. Це означає, що навіть файл у кілька гігабайт обробляється без проблем за правильного підходу.

Що варто пам'ятати при роботі з великими файлами:

- не конвертувати `reader` у список через `list(reader)` без необхідності — це завантажить усі рядки в пам'ять;
- обробляти дані рядок за рядком або невеликими батчами;
- якщо потрібна складна аналітика великих CSV — розглянути бібліотеку `pandas`, яка оптимізована саме для таких задач.

```python
import csv

with open("large_file.csv", encoding="utf-8") as file:
    reader = csv.DictReader(file)
    for row in reader:
        # кожен рядок обробляється і одразу звільняється з пам'яті
        process(row)
```

## CSV і JSON: порівняння форматів

Після заняття 16, де розглядався JSON, природно виникає питання: коли що використовувати.

| Критерій | CSV | JSON |
|---|---|---|
| Структура | плоска таблиця | вкладені об'єкти |
| Зручність для Excel | висока | низька |
| Підтримка типів даних | лише рядки | числа, булеві, null |
| Читабельність | висока для простих даних | висока для складних структур |
| Розмір файлу | компактний | більший через ключі |

Спрощено: CSV — для табличних даних і обміну з Excel; JSON — для складних вкладених структур і API.

## Типові помилки

**Кодування.** Якщо у файлі є кирилиця або інші не-ASCII символи, завжди вказуйте `encoding="utf-8"`. На Windows файли, збережені Excel, часто мають кодування `cp1251` — це варто перевіряти.

**Подвійні переноси рядків на Windows.** При відкритті файлу для запису обов'язково передавайте `newline=""`, інакше між рядками з'являться порожні рядки.

**Числа як рядки.** `csv.reader` повертає всі значення як рядки. Якщо потрібне число, його треба явно конвертувати: `int(row["age"])` або `float(row["price"])`.

## Підсумок

Модуль `csv` покриває переважну більшість задач роботи з табличними файлами. `reader` і `writer` — для простих випадків, де важлива позиція стовпця. `DictReader` і `DictWriter` — для більш зрозумілого коду, де звертання до поля за назвою важливіше за компактність. Діалекти дозволяють коректно працювати з файлами нестандартного формату. При роботі з великими файлами ітераційний підхід забезпечує стабільне споживання пам'яті.
