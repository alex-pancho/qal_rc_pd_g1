# Пошук дублікатів у CSV
Ваше завдання полягає в тому, щоб знайти дублікатні рядки у CSV-файлах.

Приблизний алгоритм:
1. Прочитайте CSV-файли "users_1.csv" та "users_2.csv".
2. Зберігайте кожен рядок у множині або словнику для виявлення дублікатів.
3. Якщо рядок вже існує у множині/словнику, це дублікат, його слід пропустити
4. Виведіть або збережіть оригінальні рядки у окремий файл "clean_users_3.csv"

## Чого не вистачає — основна логіка

Задача — знайти та прибрати дублікати. Ця логіка ще не написана. Ось орієнтир, як про це думати:

Щоб визначити, чи є рядок дублікатом, його потрібно перетворити на щось, що можна порівнювати і зберігати у множині. Словник (`dict`) не є хешованим — у множину його не покласти напряму. Але якщо перетворити словник на `tuple` пар ключ-значення через `.items()`, його можна використати як ключ.

**Варіант 1 (простіше):**
1. Зчитати обидва файли.
2. Об'єднати їх в один список.
3. Пройтися по рядках: якщо рядок ще не зустрічався — додати до результату і позначити як побачений; якщо зустрічався — це дублікат, лічильник +1.
4. Записати унікальні рядки у `clean_users_3.csv`.
5. **Вивести кількість знайдених дублікатів.**

**Варіант 2 (трохи складніше):**
1. Зчитати обидва файли.
2. Виміряти довжини l1, l2
3. перетворити в два сети. Виміряти довжини s1, s2, якщо l1 != s1 і (або) l2 != s2 то різниця довжин - дублікати, що були всередині файлу.
4. Перетин сетів (set1 & set2) - це дублікати. Порахувати через len() к-сть дублікатів
5. Обєднання сетів (set1 | set2) - це унікальні значення. Записати унікальні рядки у `clean_users_3.csv`.
6. **Вивести кількість знайдених дублікатів.**


### Виведення кількості дублікатів — обов'язкова частина

Програма повинна повідомляти результат, наприклад:

```
Знайдено дублікатів: 7
Унікальних записів збережено: 43
Файл: clean_users_3.csv
```

Це не просто зручність — це основна мета завдання. Без цього виводу незрозуміло, чи спрацювала дедублікація взагалі.

## Структура, яку варто мати в результаті

```
read_file(filepath)        → зчитує один CSV-файл, повертає список словників
write_csv(filepath, rows)  → записує список словників у файл (з заголовком!)
find_duplicates(rows)      → повертає (унікальні рядки, кількість дублікатів)
main()                     → координує все: читає, дедублікує, пише, виводить статистику
```

Функцію `find_duplicates` можна назвати інакше — головне, щоб логіка пошуку дублікатів була відокремлена від вводу/виводу.
## Підсумок

| Що є | Що потребує виправлення | Чого не вистачає |
|---|---|---|
| Структура з функціями | `DictWriter` без `fieldnames` | Логіка дедублікації |
| `pathlib` для шляхів | Відсутній `writeheader()` | Читання двох файлів |
| Типові анотації | — | Виведення кількості дублікатів |
| `if __name__ == "__main__"` | — | Запис у `clean_users_3.csv` |
