# Домашнє завдання: 2 прості сторінки

## Завдання

Створіть у Django-проєкті **дві прості сторінки**:

- головна сторінка;
- сторінка “Про мене” або “Про проєкт”.

На кожній сторінці має бути:

- окремий маршрут;
- окреме представлення;
- окремий шаблон;
- текст, переданий через `render()`.[^1]

***

## Що потрібно зробити

### 1. Створити застосунок

Наприклад:

```bash
python manage.py startapp core
```


### 2. Додати застосунок у `settings.py`

```python
INSTALLED_APPS = [
    ...
    "core",
]
```


### 3. Створити маршрути

У застосунку створіть `urls.py` і підключіть його через `include()`.

### 4. Створити 2 views

Наприклад:

- `home()`
- `about()`


### 5. Створити 1 шаблон

Наприклад:

- `base.html`



### 6. Передати дані в шаблони

У кожному view передайте хоча б 1–2 змінні:

- заголовок сторінки;
- короткий текст;
- ваше ім’я або назву проєкту.[^1]

***

## Приклад структури

```text
core/
├── urls.py
├── views.py
└── templates/
    └── base.html
```


***

# Мінімальний приклад

### `core/urls.py`

```python
from django.urls import path
from . import views

urlpatterns = [
    path("", views.home, name="home"),
    path("about/", views.about, name="about"),
]
```


### `core/views.py`

```python
from django.shortcuts import render

def home(request):
    return render(request, "base.html", {
        "title": "Головна сторінка",
        "text": "Це моя перша сторінка на Django.",
    })

def about(request):
    return render(request, "base.html", {
        "title": "Про мене",
        "text": "Мене звати ...",
    })
```


### `base.html`

```html
<h1>{{ title }}</h1>
<p>{{ text }}</p>
```


***

## Що має вийти

Після запуску проєкту сторінки мають відкриватися за адресами:

- `/`
- `/about/`

На них має відображатися текст із шаблону та дані, які передані з view.[^1]
