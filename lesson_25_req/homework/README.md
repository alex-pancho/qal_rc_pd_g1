# API Testing з Python (requests + pytest)

Автоматизовані API тести для [JSONPlaceholder](https://jsonplaceholder.typicode.com).

## Встановлення та запуск

1. Клонуйте репозиторій та перейдіть у папку проєкту:
   ```bash
   git clone <посилання-на-ваш-репозиторій>
   cd <назва-папки>
   ```

2. Встановіть залежності:
   ```bash
   pip install -r requirements.txt
   ```

3. Запустіть тести:
   ```bash
   pytest -v
   ```
