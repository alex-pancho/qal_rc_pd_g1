# Домашнє завдання

## Частина 1. Підготовка проєкту

У вже створеному Django-проєкті:

1. Встановіть **Django REST Framework**.
2. Додайте `rest_framework` до `INSTALLED_APPS`.
3. Переконайтеся, що проєкт успішно запускається.

---

## Частина 2. Створення REST API

Для однієї з моделей вашого проєкту (наприклад: `Post`, `Product`, `Task`, `Car`, `Book`, `Student` тощо):

1. Створіть файл `serializers.py`.
2. Реалізуйте `ModelSerializer`.
3. Додайте API-представлення (`APIView`).
4. Створіть маршрут:

```
/api/<objects>/
```

5. Реалізуйте:

* отримання списку об'єктів (GET);
* створення нового об'єкта (POST).

---

## Частина 3. Вкладена серіалізація

Якщо у вашому проєкті є зв'язок між моделями (`ForeignKey` або `ManyToMany`):

Наприклад:

* Автор → Статті
* Категорія → Товари
* Виробник → Автомобілі
* Студент → Курси

створіть вкладений серіалізатор так, щоб інформація про пов'язаний об'єкт поверталася всередині JSON.

Якщо зв'язків поки немає — цей пункт можна пропустити.

---

## Частина 4. Swagger

1. Встановіть **drf-spectacular**.
2. Налаштуйте генерацію OpenAPI Schema.
3. Підключіть Swagger UI.
4. Перевірте, що документація відкривається у браузері.

---

## Частина 5. Перевірка роботи

Перевірте API через Swagger:

* отримання списку;
* створення нового запису;
* правильність JSON-відповіді;
* відсутність помилок у консолі.

---

# Що необхідно здати

Надішліть посилання на GitHub-репозиторій із виконаною роботою.

У репозиторії повинні бути:

* реалізований REST API;
* серіалізатор;
* маршрути API;
* Swagger-документація;
* README з короткою інструкцією запуску проєкту.

---

# Додаткове завдання ⭐

Реалізуйте окремий endpoint:

```
/api/statistics/
```

який повертає статистику вашого проєкту у форматі JSON.

Наприклад:

```json
{
    "posts": 18,
    "users": 5,
    "comments": 47
}
```

або аналогічну статистику відповідно до предметної області вашого проєкту.
