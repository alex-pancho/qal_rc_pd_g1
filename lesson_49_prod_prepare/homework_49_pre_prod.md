# Домашнє завдання до заняття 49

## Підготовка Django-застосунку до Production

### Мета

Підготувати навчальний Django-проєкт до розгортання у Production, використовуючи безпечні налаштування та інструменти, які застосовуються в реальних проєктах.

---

# Обов'язкова частина

## Завдання 1. Підготуйте конфігурацію Production

У файлі `settings.py` виконайте такі налаштування:

* встановіть `DEBUG = False`;
* заповніть `ALLOWED_HOSTS`;
* перенесіть `SECRET_KEY` у змінні середовища;
* налаштуйте `STATIC_ROOT`;
* налаштуйте `MEDIA_ROOT`.

---

## Завдання 2. Використайте `.env`

1. Встановіть бібліотеку `python-dotenv`.
2. Створіть файл `.env`.
3. Перенесіть до нього:

   * `SECRET_KEY`;
   * `DEBUG`;
   * (за бажанням) параметри підключення до бази даних.
4. Підключіть змінні середовища у `settings.py`.

---

## Завдання 3. Оновіть `.gitignore`

Переконайтеся, що репозиторій **не містить**:

* `.env`;
* `db.sqlite3` (за потреби);
* папку `media/`;
* кеш Python (`__pycache__`).

---

## Завдання 4. Підготуйте статичні файли

Налаштуйте:

```python
STATIC_ROOT
```

та виконайте команду:

```bash
python manage.py collectstatic
```

Після виконання перевірте, що створилася папка зі статичними файлами.

---

## Завдання 5. Перевірте готовність до Production

Виконайте команду:

```bash
python manage.py check --deploy
```

Виправте всі попередження, які можете усунути.

Зробіть скріншот результату виконання команди.

---

## Завдання 6. Запустіть Gunicorn

Встановіть Gunicorn:

```bash
pip install gunicorn
```

Запустіть застосунок:

```bash
gunicorn config.wsgi:application
```

> Якщо назва вашого проєкту відрізняється від `config`, використовуйте відповідний модуль WSGI.

Переконайтеся, що застосунок успішно запускається.
